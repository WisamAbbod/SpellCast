# Screenshots

The README expects three files here:

| File | What to capture |
|---|---|
| `menu.png` | The main menu, ideally with a streak showing |
| `game.png` | Mid-round — a word landing, confetti, bonus tiles visible |
| `results.png` | The results screen with the ten best words |

Any size works; the README scales them to 230px wide. Phone screenshots
(around 1170x2532) look right.
